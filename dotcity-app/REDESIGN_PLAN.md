# 도트시티 건물 디자인 다듬기 (계획 A)

목표는 허술해 보이는 건물과 소품을 **지금 크기 그대로, 코드로 더 정교하게** 다시 그리는 것입니다.

- **PixelLab은 참고용으로만 씁니다.** 64px 이상 크기로 디자인 아이디어(색 배치, 창문, 지붕 디테일)를 뽑아 보는 데 씁니다.
- 게임 크기(1칸 = 가로 32px)에서는 PixelLab도 지금 그림과 비슷하게 나와서 게임에 직접 넣지 않습니다. 2026-11 시험 결과입니다.
- PixelLab 키는 클라우드 환경의 Network secrets(`api.pixellab.ai`, Bearer)에 등록돼 있습니다.

## 원칙
- 스프라이트는 `dotcity/index.html`의 PB/mk 그리기 함수로 그립니다. 그래야 밤 창문 불빛(`[낮색, 밤색]`), 그림자, 눈 쌓임, 계절 효과가 그대로 됩니다.
- 크기와 놓이는 자리(ox, oy, footprint)만 그대로 두고, 디자인(모양, 지붕, 창문, 색, 소품)은 새로 짭니다. 원래 그림을 따라 그리면 똑같이 나오기 때문입니다.
- 바꿀 때마다 기존과 새 그림을 나란히 비교하고, 낮·밤 화면을 확인합니다.

## 순서
1. ✅ **신호등**: 키우고 디테일 추가 (2026-11-19)
2. ✅ **철도 세트**: 대합실 역사, 시대별 기본 열차 3종, 철길, 여객 터미널 (2026-11-19)
3. ✅ **공공건물**: 소방서, 경찰서, 병원(현대), 학교, 시청. PixelLab 시안 A를 참고했습니다 (2026-11-19)
4. ✅ **랜드마크**: 경기장, 공항, 전파탑, 우주 엘리베이터, 신호등(세로형으로 다시). PixelLab 시안 A를 참고했습니다 (2026-11-19)
5. ✅ **공업구역**: 근대·현대 공장 3단계(철판 창고, 파란 셔터 공장, 사일로 공장). PixelLab 시안 B를 참고했습니다 (2026-11-19)
6. ✅ **꾸미기 소품 13종**: PixelLab 시안 B를 참고했습니다 (2026-11-19)
